2. Dominio Total de Metafields y Metaobjects

Los Metafields permiten extender el esquema de datos nativo asociando pares clave-valor fuertemente tipados a productos, variantes, clientes o pedidos. Los Metaobjects son entidades completas y reutilizables compuestas por múltiples campos, equivalentes a tablas relacionales personalizadas en Shopify.

Tipos de Datos en Metafields

📄

Texto y Primitivos

single_line_text_field, multi_line_text_field, number_integer, number_decimal, boolean, date y color.

🔗

Referencias (References)

file_reference (PDFs, videos, imágenes en CDN), product_reference, page_reference y metaobject_reference.

📚

Listas (Lists)

Array tipado: list.single_line_text_field o list.file_reference para galerías de demostración y listas de características.

⚙️

Estructuras JSON

json: Permite persistir estructuras anidadas arbitrarias cuando se requiere flexibilidad no soportada por tipos estándar.

Metafields en Liquid: Sintaxis y Filtros

En Liquid, el acceso canónico se realiza a través de la notación de objeto {{ resource.metafields.namespace.key.value }}. Regla de oro: Siempre incluir la propiedad .value para desempaquetar el objeto tipado subyacente.

Liquid snippets/render-metafields.liquid 
{% comment %} 1. Acceso a Campo Simple de Texto {% endcomment %}
{% if product.metafields.custom.fabric_origin.value != blank %}
  <p class="origin-info">Fabricación: {{ product.metafields.custom.fabric_origin.value }}</p>
{% endif %}

{% comment %} 2. Renderizado de Referencia a Archivo (File Reference - PDF / Imagen) {% endcomment %}
{% assign spec_sheet = product.metafields.custom.spec_sheet_pdf.value %}
{% if spec_sheet != blank %}
  <a href="{{ spec_sheet.url }}" target="_blank" class="btn-download">
    Descargar Documento Técnico ({{ spec_sheet.file_size | file_size }})
  </a>
{% endif %}

{% comment %} 3. Iteración sobre Lista de Referencias de Imágenes {% endcomment %}
{% assign tech_diagrams = product.metafields.custom.exploded_view_images.value %}
{% if tech_diagrams != blank %}
  <div class="technical-gallery">
    {% for image in tech_diagrams %}
      {{ image | image_url: width: 800 | image_tag: loading: 'lazy', class: 'tech-img' }}
    {% endfor %}
  </div>
{% endif %}

Metaobjects: Modelado Reutilizable y Páginas Dinámicas

Un Metaobject es un registro estructurado con una definición formal (Schema). Son ideales para entidades que se repiten a lo largo de múltiples productos, como tablas de medidas (Size Charts), perfiles de autores/diseñadores o guías de cuidado y garantía.

Liquid sections/metaobject-warranty-block.liquid 
{% comment %} Consumo de Metaobject referenciado desde el Producto {% endcomment %}
{% assign warranty_entry = product.metafields.custom.warranty_and_care.value %}

{% if warranty_entry != blank %}
  <div class="warranty-card" style="border-left: 4px solid #95bf47; padding: 1.5rem; background: #f8fafc;">
    <h3>{{ warranty_entry.policy_name }}</h3>
    <p class="coverage">Plazo de Cobertura: {{ warranty_entry.duration_months }} meses</p>
    
    {% comment %} Iterar lista interna dentro del metaobject {% endcomment %}
    <h4>Protocolo de Mantenimiento:</h4>
    <ul>
      {% for tip in warranty_entry.maintenance_tips.value %}
        <li>{{ tip }}</li>
      {% endfor %}
    </ul>
  </div>
{% endif %}

Conexión con el Theme Editor (Dynamic Sources)

En la arquitectura Online Store 2.0 (OS 2.0), los esquemas de secciones y bloques (`schema JSON`) permiten definir configuraciones que se pueden conectar dinámicamente con Metafields y Metaobjects sin alterar código.

💡

Arquitectura sin Código para Clientes

Al vincular Metafields como Dynamic Sources en el Theme Editor, los editores y gestores de catálogo de la tienda pueden cambiar especificaciones o asociar tablas de cuidado desde la interfaz visual nativa de Shopify, garantizando un acoplamiento limpio entre contenido y diseño.
