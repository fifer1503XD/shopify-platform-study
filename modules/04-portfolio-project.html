Módulo 04 • Proyecto Práctico

4. Proyecto de Portafolio: Ficha de Producto Ultra-Técnica

En este proyecto construimos una solución integral para productos de alta gama (tecnología/audio). Integramos especificaciones de ingeniería con Metafields, soporte de manuales en PDF y un Metaobject de Garantía y Cuidados con validaciones Liquid condicionales y diseño 100% adaptable para Desktop y Mobile.

Esquema del Proyecto Práctico

🧩

Metafields del Producto

  • custom.tech_specs (JSON estructurado)
  • custom.specs_pdf (file_reference para manual PDF)
🛡️

Metaobject: warranty_and_care

  • title (Single line text)
  • coverage_period (Single line text)
  • cleaning_instructions (List of text)

Código Liquid de Producción: sections/product-tech-specs.liquid

Liquid sections/product-tech-specs.liquid 
{% comment %}
  Section: Product Technical Specs & Warranty Metaobject
  Solo se renderiza si el producto posee datos de especificaciones cargados.
{% endcomment %}

{% assign specs = product.metafields.custom.tech_specs.value %}
{% assign pdf_doc = product.metafields.custom.specs_pdf.value %}
{% assign warranty = product.metafields.custom.warranty_and_care.value %}
