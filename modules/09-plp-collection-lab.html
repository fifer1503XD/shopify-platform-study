9. Creación y Arquitectura de PLP (Product Listing Page)

Una Product Listing Page (PLP) o página de colección es el epicentro de la experiencia de compra en Shopify. Mientras que la PDP convierte al comprador decidido, la PLP es responsable de guiar el descubrimiento, estructurar la navegación por facetas (filtros) y mantener tiempos de carga ultrarrápidos (<1s First Contentful Paint). En este módulo aprenderás la arquitectura técnica detrás de las colecciones en Shopify Online Store 2.0 y construirás una PLP interactiva paso a paso utilizando los productos y metafields definidos en el catálogo.

Arquitectura de Archivos y Flujo de Renderizado en Temas OS 2.0

En los temas modernos de Shopify, la página de colección no es un archivo monolítico. Se desacopla en una jerarquía modular de Templates JSON, Secciones Liquid y Snippets reutilizables:

Archivo / Componente Ubicación en Tema Responsabilidad Técnica
templates/collection.json Templates Define el orden de secciones (banner, filtros, grid de productos, enriquecedores SEO) y almacena la configuración del Theme Editor.
sections/main-collection-product-grid.liquid Sections Controla el wrapper del grid, la paginación (paginate), el contenedor de facetas y la inyección del bucle for product in collection.products.
snippets/facets.liquid Snippets Renderiza el sistema de filtrado nativo mediante el objeto collection.filters (soporta filtros por precio, tags, disponibilidad y metafields).
snippets/card-product.liquid Snippets Componente atómico de tarjeta de producto. Renderiza thumbnail, badges, precio con descuento, color swatches y metafields de producto.
snippets/pagination.liquid Snippets Renderiza los enlaces accesibles de navegación entre páginas del catálogo respetando la estructura semántica SEO.
Regla de Oro de Rendimiento: Paginación Mandatoria

Shopify exige que cualquier iteración sobre collection.products esté envuelta en un tag {% paginate collection.products by N %} (máximo 50 productos por página). Intentar iterar sin paginar arrojará un error de compilación Liquid o limitará automáticamente a 50 ítems. La mejor práctica para tiendas enterprise es paginar entre 12 y 24 productos para optimizar el DOM Size y la métrica INP (Interaction to Next Paint).

Paso 1: Configurar la Colección en Shopify Admin (Smart vs Manual)

Una colección puede crearse de dos formas:

  • Manual: Curas individualmente cada producto añadiéndolo a mano. Ideal para colecciones de autor o "Lo más vendido del mes".
  • Automática (Smart Collection): Creas condiciones lógicas como Product tag is equal to "sustainable" o Product type is equal to "Wearables". Cualquier producto nuevo que coincida se indexa automáticamente.
Colección Automática vía Admin GraphQL API 
mutation CreateSmartCollection {
  collectionCreate(input: {
    title: "Colección Sustentable & Tech",
    descriptionHtml: "<p>Prendas y gadgets con certificación ecológica.</p>",
    ruleSet: {
      appliedDisjunctively: false,
      rules: [
        {
          column: TAG,
          relation: EQUALS,
          condition: "eco-friendly"
        },
        {
          column: VARIANT_PRICE,
          relation: GREATER_THAN,
          condition: "0"
        }
      ]
    }
  }) {
    collection {
      id
      handle
      title
    }
    userErrors {
      field
      message
    }
  }
}

Paso 2: Construir la Sección Liquid con Paginación (`main-collection-product-grid.liquid`)

Implementa la estructura de grid responsivo con soporte para ordenamiento y paginación en el servidor:

sections/main-collection-product-grid.liquid 
{%- paginate collection.products by section.settings.products_per_page -%}
  <div class="collection-page-container">
    
    <!-- Barra Superior: Total de Resultados y Ordenamiento -->
    <div class="collection-toolbar">
      <span class="results-count">
        {{ collection.products_count }} {{ 'products.general.items_found' | t }}
      </span>

      <div class="sort-by-wrapper">
        <label for="SortBy">Ordenar por:</label>
        <select id="SortBy" name="sort_by" class="sort-select" onchange="location.href = this.value;">
          {%- for option in collection.sort_options -%}
            <option value="{{ option.value | prepend: '?sort_by=' }}" 
              {% if option.value == collection.sort_by %}selected{% endif %}>
              {{ option.name }}
            </option>
          {%- endfor -%}
        </select>
      </div>
    </div>

    <div class="collection-layout">
      <!-- Sidebar de Filtros Nativos -->
      <aside class="collection-facets-sidebar">
        {% render 'facets', results: collection %}
      </aside>

      <!-- Grid de Productos -->
      <div class="product-grid" id="ProductGridContainer">
        {%- if collection.products.size > 0 -%}
          <ul class="grid grid-3-col">
            {%- for product in collection.products -%}
              <li class="grid-item">
                {% render 'card-product', 
                  card_product: product, 
                  show_metafields: section.settings.show_metafields,
                  show_swatches: true 
                %}
              </li>
            {%- endfor -%}
          </ul>
          
          {%- if paginate.pages > 1 -%}
            {% render 'pagination', paginate: paginate %}
          {%- endif -%}
        {%- else -%}
          <div class="no-products-found">
            <p>No se encontraron productos en esta colección.</p>
          </div>
        {%- endif -%}
      </div>
    </div>
  </div>
{%- endpaginate -%}

Paso 3: Creación del Snippet Reutilizable `card-product.liquid` con Metafields

La tarjeta de producto debe renderizar de forma limpia los metadatos extendidos del producto (ej: badge de sustentabilidad, material, opciones de color):

snippets/card-product.liquid 
<div class="product-card" data-product-id="{{ card_product.id }}">
  <!-- Imagen y Badges -->
  <div class="card-media-wrapper">
    {%- if card_product.compare_at_price > card_product.price -%}
      <span class="badge badge-sale">Oferta</span>
    {%- elsif card_product.tags contains 'nuevo' -%}
      <span class="badge badge-new">Nuevo</span>
    {%- endif -%}

    <a href="{{ card_product.url }}" class="media-link">
      <img 
        src="{{ card_product.featured_image | image_url: width: 600 }}" 
        alt="{{ card_product.featured_image.alt | default: card_product.title | escape }}"
        loading="lazy"
        width="600"
        height="600"
        class="card-img"
      />
    </a>
  </div>

  <!-- Información del Producto -->
  <div class="card-content">
    <span class="card-vendor">{{ card_product.vendor }}</span>
    <h3 class="card-title">
      <a href="{{ card_product.url }}">{{ card_product.title }}</a>
    </h3>

    <!-- Render de Metafields en Card -->
    {%- if card_product.metafields.custom.sustainability_score.value != blank -%}
      <div class="card-meta-tag eco-tag">
        🌿 Eco Score: {{ card_product.metafields.custom.sustainability_score.value }}
      </div>
    {%- endif -%}

    <!-- Precios -->
    <div class="card-price-row">
      <span class="price-regular">{{ card_product.price | money }}</span>
      {%- if card_product.compare_at_price > card_product.price -%}
        <s class="price-compare">{{ card_product.compare_at_price | money }}</s>
      {%- endif -%}
    </div>

    <!-- Swatches de Color (Variantes) -->
    {%- for option in card_product.options_with_values -%}
      {%- if option.name == 'Color' or option.name == 'Colour' -%}
        <div class="card-swatches">
          {%- for value in option.values -%}
            <span class="swatch-dot" title="{{ value }}"></span>
          {%- endfor -%}
        </div>
      {%- endif -%}
    {%- endfor -%}
  </div>
</div>

Storefront API GraphQL: Colección con Filtros y Metafields 
query GetCollectionWithFacetsAndMetafields($handle: String!, $filters: [ProductFilter!]) {
  collection(handle: $handle) {
    id
    title
    description
    products(first: 12, filters: $filters, sortKey: PRICE, reverse: false) {
      pageInfo {
        hasNextPage
        hasPreviousPage
      }
      filters {
        id
        label
        type
        values {
          id
          label
          count
          input
        }
      }
      edges {
        node {
          id
          title
          handle
          vendor
          productType
          featuredImage {
            url
            altText
            width
            height
          }
          priceRange {
            minVariantPrice {
              amount
              currencyCode
            }
          }
          # Metafields en la Storefront API
          sustainabilityScore: metafield(namespace: "custom", key: "sustainability_score") {
            value
            type
          }
          materialComposition: metafield(namespace: "custom", key: "material") {
            value
          }
        }
      }
    }
  }
}
