Customizing Themes (Personalización de Temas en Shopify)

Aprende sobre las distintas opciones de storefronts en el ecosistema de Shopify, la arquitectura Online Store 2.0, personalización sin código con el Theme Editor y desarrollo de secciones Liquid personalizadas para colecciones estacionales.

Sección 1: Shopify Storefront Customization and Themes

Los Storefronts (escaparates de venta) permiten brindar experiencias de compra únicas en cualquier punto de contacto donde se encuentren los clientes: sitios web, aplicaciones móviles, terminales de punto de venta e incluso videojuegos. La tienda online basada en web es la variante más popular, pero no es la única.

Todas las variantes se conectan con la lógica de negocio y los datos centralizados de Shopify mediante el Shopify Admin o las APIs públicas:

Tipo de Storefront Online Store (Clásica) Custom Storefront (Hydrogen) Custom Storefront (Self-Hosted) Mobile Apps (Nativas)
Resumen del Stack Web construida con Liquid, hosteada 100% por Shopify. Web construida con Hydrogen (React/Remix), hosteada en Shopify Oxygen. Web construida con frameworks JS (Next.js, Angular), auto-alojada. Apps nativas iOS y Android con SDKs móviles de Shopify.
Ejemplo Real Netflix Shop Nour Hammour YouFoodz Fashion Nova App
Infraestructura de Hosting Shopify Global Cloud Shopify Oxygen (Edge global) Plataforma a elección (AWS, Vercel, Azure) App Store / Google Play
Tecnologías de Desarrollo Liquid, HTML5, CSS3, Vanilla JS Hydrogen, React, Remix, Tailwind Next.js, Nuxt, Angular, Ruby, etc. Swift, Kotlin, React Native, Flutter
Acceso a Datos de Shopify Motor de renderizado Liquid nativo Storefront API (GraphQL) Storefront API (GraphQL) Storefront API & Mobile Checkout SDKs

Tipos de Temas de Shopify

🛍️

1. Temas Preconstruidos (Shopify Theme Store)

Opciones gratuitas y de pago creadas por Shopify y partners certificados. Todos los temas de la Theme Store son rigurosamente auditados en rendimiento (Core Web Vitals), accesibilidad y seguridad. Se pueden personalizar sin código mediante el Theme Editor o editando su código Liquid.

⚡

2. Temas Custom a Medida

Desarrollados desde cero para marcas con requerimientos de UX/UI complejos, integraciones ERP avanzadas o flujos B2B únicos que exceden las capacidades de un tema genérico.

💼

Peticiones Habituales de Clientes en el Mundo Real

  • Expansión Global y Multidivisa: Configurar selectores de idiomas y divisas nativos con Shopify Markets.
  • Nuevas Líneas de Productos: Adaptar la ficha de producto para desplegar tablas de medidas en indumentaria versus especificaciones en accesorios.
  • Migración a Online Store 2.0: Modernizar temas heredados a plantillas JSON modulares para admitir fuentes dinámicas de Metafields.
  • Expansión B2B: Implementar el tema oficial Trade de Shopify diseñado para listas de precios al por mayor y pedidos masivos.
  • Headless Enterprise: Desacoplar el frontend con Hydrogen & Oxygen para empresas con stacks tecnológicos heterogéneos.
⭐

Mejores Prácticas de Desarrollo de Temas (Shopify Best Practices)

1. Performance ante todo: Mínimo JavaScript bloqueante y carga diferida de imágenes.
2. Propósito definido (Purpose-built): Evitar sobrecargar temas con opciones innecesarias.
3. UX de primer nivel y Mobile First: El 75%+ de las transacciones ocurren en smartphones.
4. Accesibilidad (WCAG): Estructuras semánticas y contrastes legibles.
5. Simplicidad de personalización: Diseñar esquemas intuitivos para administradores no técnicos.

Sección 2: Customizing Horizon with the Theme Editor

Comprender la jerarquía visual de un tema es indispensable antes de realizar personalizaciones. Una página típica de e-commerce en Online Store 2.0 se organiza en 5 capas:

Nivel Componente Descripción Técnica
1 The Layout La base estructural del tema (ej. layout/theme.liquid). Aloja elementos persistentes globales como encabezados (Header) y pies de página (Footer).
2 The Template Controla lo que se renderiza en una página específica (ej. templates/product.json, templates/index.json).
3 Section Groups Contenedores modulares de grupos de secciones y app blocks (ej. sections/header-group.json).
4 The Sections Módulos de contenido reutilizables y reordenables que se inyectan en plantillas JSON (archivos .liquid en /sections).
5 The Blocks Micro-componentes anidados dentro de una sección (títulos, botones, textos, ratings) que pueden agregarse, borrarse o reordenarse libremente.
H

El Tema Horizon: El Estándar de Referencia OS 2.0

Horizon es una plantilla ultra-optimizada diseñada por Shopify para demostrar las mejores prácticas de la arquitectura Online Store 2.0:

  • Plantillas 100% JSON en todas las páginas para admitir App Blocks y Theme Blocks.
  • Enfoque Mobile-First con uso mínimo de JavaScript para garantizar tiempos de carga instantáneos.
  • Máxima accesibilidad y facilidad de personalización drag-and-drop.
🛠️

Práctica: Personalización con el Theme Editor

  1. Confirmar instalación de Horizon: En Online Store > Themes, verifica que Horizon esté añadido a tu biblioteca.
  2. Explorar Secciones: Haz clic en Customize (Personalizar). Navega por las páginas (Home, Catalog, Contact, Featured Collections) y experimenta añadiendo secciones de formulario de contacto o artículos de blog.
  3. Explorar Theme Settings: En la barra lateral izquierda, abre Theme Settings para configurar la tipografía corporativa, paleta de colores y enlaces a redes sociales.

Sección 3: Theme Building Blocks & Directory Structure

Todos los temas de Shopify siguen una estructura estandarizada de directorios obligatoria. Esta organización divide el código en archivos de marcado Liquid, recursos de soporte (assets), configuración JSON y snippets reutilizables:

File Tree Estructura Estándar de un Tema Shopify OS 2.0 
📦 shopify-theme/
├── 📁 assets/       # CSS, JavaScript compilado, fuentes e imágenes estáticas del tema
├── 📁 blocks/       # Theme Blocks reutilizables independientes
├── 📁 config/       # settings_schema.json y settings_data.json (configuración del theme editor)
├── 📁 layout/       # theme.liquid (plantilla base de layout global)
├── 📁 locales/      # Archivos de traducción y localización multi-idioma (es.json, en.default.json)
├── 📁 sections/     # Módulos Liquid y grupos JSON de secciones (header, footer, banners)
├── 📁 snippets/     # Micro-trozos de Liquid reutilizables incluidos vía {% render 'snippet' %}
└── 📁 templates/    # Plantillas de páginas (.json o .liquid)
    └── 📁 customers/ # Plantillas específicas de clientes (account, login, register, addresses)
Componente Tipo de Archivo Ubicación en el Tema Propósito Principal
Layout .liquid /layout Esqueleto HTML envolvente (encabezados, scripts globales, footer).
Template .json / .liquid /templates Estructura y secciones de páginas (Home, Producto, Colección, Carrito).
Section Groups .json /sections Contenedores para encabezados (header-group) y pies de página (footer-group).
Sections .liquid /sections Módulos de UI con lógica Liquid y esquema de configuración {% schema %}.
Blocks Declarados en schema Dentro de Sections / Blocks Sub-elementos dinámicos configurables por el comerciante.

Páginas Clave en un E-Commerce de Shopify

index.json

Página de inicio (Home Page). El punto de entrada principal donde se comunican los valores de marca.

collection.json

Listado de productos pertenecientes a una colección específica con filtros y paginación.

product.json

Página de detalle de producto (PDP) con selector de variantes, precio, compra y metafields.

cart.json

Resumen del carrito de compras antes del paso al checkout seguro.

customers/account.json

Portal privado para consultar historial de compras, estado del envío y direcciones.

blog.json & article.json

Motor de publicaciones y contenidos editoriales para SEO y marketing de contenidos.

Sección 4: Lab: Build a Collection Page with a Liquid Section

☀️

Escenario de Negocio: Preventa Estacional de "Stylish Stitches"

Lily está fascinada con la velocidad de desarrollo de su tienda. Ahora su equipo ha terminado la Colección de Verano y desea comenzar a aceptar Preventas (Pre-orders) de inmediato. Lily necesita una plantilla de colección estacional que sea reutilizable tanto para la temporada actual como para futuras colecciones de invierno o primavera.

Requerimientos de la Plantilla:
1. Título y descripción de la colección actual.
2. Sección de Llamado a la Acción (CTA) para invitar a la preventa con texto configurable.
3. Grilla de productos vinculados a la colección.

1

Paso 1: Crear la Colección de Verano en el Shopify Admin

En el Admin, ve a Products > Collections > Create collection. Asigna el título Colección de Verano 2026, agrega una descripción atractiva y añade 2 o 3 productos de indumentaria. Guarda la colección.

2

Paso 2: Crear la Nueva Plantilla JSON en el Theme Editor

Abre el Theme Editor (Online Store > Themes > Customize). En el menú desplegable superior de páginas:

  1. Selecciona Collections y haz clic en ⊕ Create template.
  2. Nombre de la plantilla: seasonal-collection.
  3. Basada en: Default collection.
3

Paso 3: Crear la Sección Liquid sections/call-to-action.liquid

En el editor de código (o vía Shopify CLI local), crea el archivo sections/call-to-action.liquid con el siguiente código Liquid de producción y su respectivo schema:

Liquid sections/call-to-action.liquid 
{% comment %}
  Section: Call to Action para Colecciones Estacionales (Pre-orders)
  Permite a Lily personalizar anuncios de preventa y enlaces directos.
{% endcomment %}

<div class="seasonal-cta-banner page-width" style="background: #f8fafc; border: 1px solid #e2e8f0; border-radius: 12px; padding: 2rem; margin: 2rem auto; text-align: center;">
  <span style="font-size: 0.8rem; font-weight: 700; text-transform: uppercase; color: #059669; letter-spacing: 0.05em;">
    {{ section.settings.subheading | default: '¡Preventa Exclusiva!' }}
  </span>
  
  <h2 style="font-size: 1.8rem; font-weight: 800; color: #0f172a; margin: 0.5rem 0;">
    {% if section.settings.custom_title != blank %}
      {{ section.settings.custom_title }}
    {% else %}
      ¡La colección {{ collection.title }} ya está disponible!
    {% endif %}
  </h2>

  {% if section.settings.cta_text != blank %}
    <div style="font-size: 1rem; color: #475569; max-width: 650px; margin: 0 auto 1.5rem; line-height: 1.6;">
      {{ section.settings.cta_text }}
    </div>
  {% endif %}

  {% if section.settings.button_label != blank %}
    <a href="{{ section.settings.button_link | default: '#product-grid' }}" style="display: inline-block; background: #0f172a; color: #ffffff; padding: 0.85rem 1.75rem; border-radius: 8px; font-weight: 700; text-decoration: none; transition: background 0.2s;">
      {{ section.settings.button_label }}
    </a>
  {% endif %}
</div>

4

Paso 4: Integrar la Sección en la Plantilla JSON collection.seasonal-collection.json

Edita el archivo templates/collection.seasonal-collection.json para posicionar el bloque call_to_action entre el banner principal de la colección y la grilla de productos:

JSON templates/collection.seasonal-collection.json 
{
  "sections": {
    "banner": {
      "type": "main-collection-banner",
      "settings": {
        "show_collection_description": true,
        "show_collection_image": true
      }
    },
    "call_to_action": {
      "type": "call-to-action",
      "settings": {
        "subheading": "Edición Limitada de Verano",
        "custom_title": "¡Reserva tus prendas de verano antes del lanzamiento oficial!",
        "button_label": "Ver Catálogo Completo"
      }
    },
    "product_grid": {
      "type": "main-collection-product-grid",
      "settings": {
        "products_per_page": 16,
        "columns_desktop": 4
      }
    }
  },
  "order": [
    "banner",
    "call_to_action",
    "product_grid"
  ]
}
5

Paso 5: Asignar la Plantilla y Publicar en el Menú Principal

  1. En el Admin de Shopify, ve a Products > Collections y abre tu Colección de Verano 2026.
  2. En el panel lateral derecho, en Theme template, selecciona seasonal-collection y guarda los cambios.
  3. Ve a Online Store > Navigation > Main menu y añade el enlace hacia All Collections o la colección de verano directamente para que los clientes puedan acceder desde el menú principal.
