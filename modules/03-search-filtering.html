3. Filtrado y Búsqueda con Datos Personalizados

Las tiendas enterprise demandan sistemas de filtrado por facetas (Facet Filtering) avanzados, como filtrar colecciones por rango de frecuencia, tipo de material o compatibilidad, alimentados directamente por Metafields.

Shopify Search & Discovery App

La aplicación oficial Shopify Search & Discovery permite activar filtros nativos basados en:

  • Disponibilidad de stock (`filter.v.availability`).
  • Rango de precios (`filter.v.price.gte` / `filter.v.price.lte`).
  • Opciones de producto (`filter.v.option.color`).
  • Metafields personalizados (`filter.p.m.custom.material` o `filter.p.m.custom.connectivity`).

Storefront Filtering API & AJAX Rendering

Para crear una experiencia de filtrado instantánea sin recargar la página completa, consumimos la Shopify Section Rendering API pasando los parámetros de filtro mediante JavaScript (Fetch).

JavaScript (ES6+) assets/collection-filters.js 
// Implementación de Facet Filter reactivo con Section Rendering API
class CollectionFilters {
  constructor(formElement, gridContainerId) {
    this.form = formElement;
    this.gridContainer = document.getElementById(gridContainerId);
    this.bindEvents();
  }

  bindEvents() {
    this.form.addEventListener('change', () => this.applyFilters());
  }

  async applyFilters() {
    const formData = new FormData(this.form);
    const params = new URLSearchParams(formData);
    
    // Indicamos a Shopify que solo re-renderice la sección de grilla de productos
    params.set('section_id', 'main-collection-product-grid');
    
    // Actualizamos URL en el navegador sin recargar
    window.history.pushState({}, '', `${window.location.pathname}?${params.toString()}`);

    try {
      this.gridContainer.classList.add('is-loading');
      
      const response = await fetch(`${window.location.pathname}?${params.toString()}`);
      const htmlText = await response.text();
      
      const parser = new DOMParser();
      const doc = parser.parseFromString(htmlText, 'text/html');
      const newGridContent = doc.getElementById('main-collection-product-grid');

      if (newGridContent) {
        this.gridContainer.innerHTML = newGridContent.innerHTML;
      }
    } catch (error) {
      console.error('Error al aplicar filtros de colección:', error);
    } finally {
      this.gridContainer.classList.remove('is-loading');
    }
  }
}
