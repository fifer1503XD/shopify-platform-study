14. Creación y Gestión de Draft Orders en Shopify Admin

Los Draft Orders (Borradores de Pedido) son uno de los motores operativos más potentes y versátiles del back-office de Shopify. Permiten al equipo de soporte, ventas corporativas y desarrolladores crear órdenes manuales en nombre de clientes, sortear el flujo regular del storefront, cotizar ventas mayoristas (B2B), agregar productos personalizados fuera de catálogo y enviar enlaces de facturación directa con pasarela de pago protegida.

1. ¿Qué es un Draft Order y cuándo utilizarlo?

A diferencia de una orden estándar generada en el checkout público por el comprador, un Draft Order se origina en el panel de administración o mediante la DraftOrder API (GraphQL / REST). Permite estructurar una cotización antes de que se convierta en una venta formal (Order).

📞 1. Pedidos Telefónicos & Customer Support

Cuando un cliente experimenta dificultades técnicas en la pasarela o prefiere cerrar la compra por llamada/WhatsApp, el agente crea el borrador con los productos requeridos y le despacha una factura con link de pago seguro en 1 clic.

🏢 2. Ventas Mayoristas & B2B Invoicing

Para cotizaciones corporativas de alto volumen con términos de pago especiales (Net 30, Net 60), descuentos por volumen ad-hoc y tarifas de flete logístico negociadas que no existen en el storefront público.

✨ 3. Productos a Medida (Custom Items)

Permite cobrar por servicios especiales (ej. "Grabado láser conmemorativo", "Mano de obra técnica", "Garantía extendida") creando un ítem con precio y peso arbitrarios sin necesidad de crear un producto en el catálogo permanente.

🏷️ 4. Descuentos y Precios Excepcionales

Aplicación de descuentos de cortesía en porcentaje o monto fijo directamente en la línea de producto o sobre el total, sin tener que crear un código de cupón público que otros usuarios puedan descubrir.

2. Anatomía y Flujo Paso a Paso en el Shopify Admin

Para crear un borrador desde el panel de control:

1
Navegación a Orders > Drafts

En el menú lateral del Admin, abre la sección Orders y selecciona Drafts. Haz clic en el botón superior derecho Create order (o Crear borrador de pedido).

2
Selección de Productos vs. Custom Items

Puedes combinar dos tipos de elementos en el pedido:

  • Productos del catálogo existente: Se buscan por título o SKU y descuentan inventario una vez confirmada la orden o al presionar "Reserve items".
  • Add custom item (Ítem personalizado): Define un nombre, precio unitario, cantidad, si requiere envío y peso específico para envíos. Ideal para presupuestos a medida.
3
Asignación de Cliente, Envío e Impuestos

En el panel derecho, vincula un perfil de cliente existente o crea uno nuevo con su correo y teléfono. Shopify calculará automáticamente las tarifas de envío e impuestos según la dirección de entrega, o te permitirá ingresar una tarifa de flete manual personalizada (ej. "Flete Express Bodega $0 - Cortesía").

4
Envío de Factura (Send Invoice) o Cobro Inmediato

Una vez armado el borrador, cuentas con 3 caminos para procesar el pago:

  • Send invoice (Enviar factura): Despacha un correo electrónico corporativo con un botón "Completar tu compra" que redirige al cliente al checkout oficial con los datos pre-cargados.
  • Collect payment (Cobrar con tarjeta): El agente ingresa los datos de tarjeta de crédito suministrados por teléfono de forma segura.
  • Mark as paid (Marcar como pagado): Para órdenes abonadas por transferencia bancaria directa, efectivo contra entrega o cheque.

3. Automatización Backend con Shopify GraphQL Admin API

En proyectos de arquitectura Headless o integraciones con CRMs (HubSpot, Salesforce) y ERPs (SAP, Odoo), los borradores de pedidos se generan y facturan mediante mutaciones de GraphQL.

MUTATION: draftOrderCreate & draftOrderInvoiceSend (GraphQL) 
# 1. Crear el borrador con ítems de catálogo + Custom Item + Descuento
mutation CreateCustomDraftOrder($input: DraftOrderInput!) {
  draftOrderCreate(input: $input) {
    draftOrder {
      id
      name
      totalPriceSet {
        shopMoney {
          amount
          currencyCode
        }
      }
      invoiceUrl
      status
    }
    userErrors {
      field
      message
    }
  }
}

mutation SendDraftInvoice($id: ID!, $email: EmailInput) {
  draftOrderInvoiceSend(id: $id, email: $email) {
    draftOrder {
      id
      status
    }
    userErrors {
      field
      message
    }
  }
}
